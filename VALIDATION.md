# Проверка версии 2.1

Дата: 19 октября 2026.

- APK собран успешно: assembleDebug, package ru.local.bitrixtasks, versionCode 12.
- Минимальная версия: API 24 (Android 7.0); targetSdk/compileSdk: 34. Для java.time подключён core library desugaring.
- Автоматические тесты: 34 из 34 успешно, ошибок нет.
- 18 тестов API и моделей, включая получение полного задания и загрузку чек-листа через task.checklistitem.getlist.
- 14 проверок экранов Robolectric на API 29 и 34, включая изменение/снятие срока, отмену редактирования и выбора времени, отказ API без изменения прежнего срока и возможность повторного сохранения.
- Экраны подключения, списка задач и изменения срока отрисованы средствами Android в Robolectric (API 29, 360 × 780 dp) и визуально проверены. Дополнительный локальный сценарий отрисовки также выполнен успешно; он не включён в 27 регрессионных тестов.
- Android Lint: 0 ошибок, 3 предупреждения. dataExtractionRules применяется с API 31; на API 29–30 резервное копирование отключено через allowBackup и fullBackupContent. Ещё два предупреждения относятся к длине контуров оригинального логотипа; геометрия сохранена точно.
- Подпись APK проверена apksigner: успешно, схема v2.
- Отдельный экран настроек проверен в тестах: смена адреса вебхука, пресеты «Завтра» и «через N дней», выбор времени и применение срока к новой задаче.
- Локальный SQLite-кэш и очередь операций проверены на API 24 и 34; данные задач и ожидающие операции корректно сохраняются и очищаются.
- Синхронизация при `onResume` добавлена для экрана списка: при возвращении приложения на передний план отправляется очередь и запрашивается свежая страница задач.
- Чек-лист загружается отдельным запросом task.checklistitem.getlist после tasks.task.get. APK версии 2.1 (versionCode 12) готов к установке на HONOR 20 LITE (Android 10).
