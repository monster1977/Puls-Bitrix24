# Фирменное оформление

Источник: https://grf.pro/ — логотип и вычисленные цвета элементов страницы, полученные 19 октября 2026 года по запросу пользователя.

`grf-logo-original.svg` содержит исходный SVG сайта без изменения геометрии. В `res/drawable/grf_logo.xml` те же 11 контуров преобразованы в Android VectorDrawable. Первые четыре контура образуют знак для адаптивной иконки приложения; знак центрирован в безопасной области. Для Android 13 и выше предусмотрен монохромный слой.

| Назначение | Цвет |
| --- | --- |
| Зелёный сайта, активные элементы управления | `#2E8941` |
| Графитовый фон шапки и иконки | `#333333` |
| Логотип и надписи на кнопках | `#FFFFFF` |
| Основные кнопки: затемнённый зелёный для контраста | `#2B803D` |
| Зелёный текст | `#236B33` |
| Светлый зелёный фон дополнительных действий | `#EAF3EB` |
| Фон экранов | `#F5F6F5` |

Имя приложения «Пульс · Задачи» и идентификатор `ru.local.bitrixtasks` сохранены для обновления установленной версии. Контуры оригинального логотипа сохранены точно; предупреждения Lint о длине двух векторных контуров приняты осознанно.
