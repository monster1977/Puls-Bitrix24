# Пульс · Задачи для Bitrix24

Независимое нативное Android-приложение для просмотра, создания, изменения крайнего срока и завершения задач Bitrix24 через входящий вебхук. Интерфейс на русском. **Android 7.0 и выше (minSdk 24)**.

## Установка и подключение

1. Перенесите `Puls-Bitrix24-Android7.apk` на Android-телефон и откройте файл. Если Android запросит разрешение на установку из этого источника, разрешите установку для используемого файлового менеджера или браузера.
2. Запустите **«Пульс · Задачи»**. Кнопка **«Посмотреть демоверсию»** позволяет проверить приложение без аккаунта.
3. На своём портале Bitrix24 откройте раздел разработчика → **Другое → Входящий вебхук**. Название раздела может зависеть от интерфейса портала.
4. Выдайте вебхуку доступ **«Задачи» (`task`)**. Скопируйте адрес для REST API целиком: `https://ваш-портал/rest/ID/секрет/`.
5. Вставьте этот адрес в приложение и нажмите **«Подключить портал»**. Проверка подключения читает первую страницу задач; она не создаёт и не меняет задачи.

Действия выполняются от имени **владельца вебхука** и с его правами. Для отдельных учётных записей участникам команды нужны собственные вебхуки. Поле «Мои» означает задачи, где исполнитель — владелец подключённого вебхука. Реальный секрет не включён в исходники и APK.

## Возможности

- Активные, завершённые и все доступные задачи.
- Фильтр по исполнителю, серверный поиск по названию, загрузка следующих страниц.
- Карточка с описанием, исполнителем, статусом, сроком и важностью.
- Редактирование названия задачи с сохранением через вебхук или локальную очередь.
- Отображение чек-листа задачи с отметками выполненных пунктов.
- Создание задачи: название, описание, числовой ID исполнителя, необязательный срок с временем и приоритет.
- Изменение крайнего срока в карточке задачи: выбор даты и времени, снятие срока, отдельное сохранение и отмена. При ошибке прежний срок сохраняется в интерфейсе.
- Меню «Настройки» в шапке: изменение адреса вебхука и срок по умолчанию для новых задач — без срока, завтра или через заданное число дней, с выбором времени.
- Режим синхронизации: локальный кэш задач и надёжная очередь создания, завершения и изменения срока. При отсутствии вебхука приложение продолжает работать с локальными данными, а при следующем доступном соединении отправляет накопленные изменения и обновляет кэш.
- При возвращении приложения на передний план экран списка автоматически запускает синхронизацию; открытые формы редактирования не прерываются.
- Завершение с подтверждением; итоговый статус берётся из ответа портала, включая статус «На контроле».
- Открытие задачи в браузере без передачи вебхука в ссылке.
- Локальный деморежим с созданием и завершением примеров.
- Понятные сообщения при проблемах подключения, истёкшем/отозванном вебхуке, нехватке прав и лимитах API.

В форме создания ID исполнителя по умолчанию совпадает с владельцем вебхука. ID коллеги можно найти в адресе его профиля: `/company/personal/user/123/`. Даты показываются в часовом поясе телефона. Для изменения откройте карточку → «Изменить крайний срок» → «Выбрать дату и время» → «Сохранить срок». Кнопка «Убрать срок» снимает срок после сохранения. Права и ограничения на изменение срока проверяет Bitrix24; приложение показывает итоговое значение из ответа портала.

## Оформление версии 1.3

В шапке используется оригинальный логотип «ГРАФИТ» с [grf.pro](https://grf.pro/), а в иконке приложения — знак из четырёх ромбов. Цветовая гамма: графитовый, зелёный и белый. Оттенки кнопок и текста адаптированы для читаемости. Исходный SVG и описание палитры находятся в папке `branding`.

## Хранение и ограничения версии 1.2

Вебхук шифруется AES-GCM; ключ находится в Android Keystore. Секрет не журналируется. HTTPS обязателен, перенаправления API запрещены, сертификаты проверяются стандартными средствами Android. Резервное копирование и перенос данных приложения отключены. Кнопка отключения удаляет сохранённое подключение с устройства; для отзыва самого вебхука удалите его в Bitrix24. Снимки экрана приложения заблокированы системным флагом защиты.

Задачи и очередь изменений хранятся локально в SQLite. Офлайн-синхронизация не является push-каналом: приложение проверяет вебхук при обновлении списка или следующем открытии. Push-уведомлений, редактирования других полей задачи, комментариев, вложений, выбора сотрудника из справочника и OAuth в этой версии нет. Форматирование описаний Bitrix24 выводится обычным текстом.

Если задача требует обязательного результата или дополнительных действий для завершения, выполните их в Bitrix24 через кнопку открытия задачи. После сетевого сбоя при создании сначала обновите список, чтобы избежать повторного создания: сервер мог обработать запрос до потери соединения. Приложение автоматически не повторяет изменяющие запросы.

Поставляемый APK — **тестовая debug-сборка для прямой установки**. Публикация в Google Play не выполнялась. В проекте compileSdk/targetSdk 34; перед публикацией нужно обновить целевой SDK под действующие требования магазина и настроить собственную release-подпись.

## Исходники и сборка

Технологии: Java 17, стандартные Android Views, `HttpsURLConnection`, `org.json`, Android Keystore. Сторонних библиотек в рабочей части приложения нет. Gradle 8.2 / Android Gradle Plugin 8.2.0.

Откройте папку проекта в Android Studio, установите Android SDK Platform 34 и Build Tools 34.0.0, выберите JDK 17. Studio создаст `local.properties` с локальным путём к SDK. В Windows можно выполнить:

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

В macOS/Linux:

```sh
sh gradlew assembleDebug testDebugUnitTest lintDebug
```

APK появится в `app/build/outputs/apk/debug/`. При первой сборке нужен интернет для Gradle и тестовых зависимостей. Тесты Robolectric используют JVM-модели Android 10 (API 29) и Android 14 (API 34), а не физическое устройство. Для локальной сборки можно передать путь к отладочному ключу через переменную `B24_DEBUG_KEYSTORE`; без неё применяется стандартный debug-keystore Android.

Структура:

- `MainActivity.java` — экраны, сохранение состояния при повороте и фоновые операции.
- `BitrixApi.java` — REST-вызовы, фильтры и постраничная загрузка.
- `SecureStore.java` — шифрование подключения.
- `Webhook.java` — строгая проверка адреса.
- `Task.java` — статусы, сроки и поля задачи.
- `ClientTest.java`, `ScreenTest.java` — тесты логики и пользовательских сценариев.
